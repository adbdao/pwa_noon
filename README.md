# 《日中時刻》的原始碼 noon for PWA  
  
### 查詢日中時刻的網頁程式。一時異想天開，現在AI很強，不如用AI寫個網頁查日中程式。因為想持【過午不食戒】的人，常常會問：如何得知當天日中時刻？吃飯才不會過午？  
>### 一般的APP都不是專門計算日中時刻，而且有廣告。所以想自己寫  
### 製作中用Google的AI來製作。叫AI寫函數來查詢：當地日中時刻，以及我所在的城市名稱。這遠超過我的編程能力！但是以後我也無法維護，因為我也看太不懂AI的程式碼！  
>### 後來檢查及修訂，也都用AI，能檢查出：日出角度計算的誤差、伺服器可能回傳的問題…  
---  
> 展示網址：  https://adbdao.github.io/pwa_noon/index.html  
>###  漸進式網站PWA  
  1. Android系統上，請用Chrome瀏覽器開啟。會自動跳出〔安裝應用程式〕對話方塊。或者手動按〔點此安裝APP〕按鈕  
  2. iPhone系統上，請在瀏覽器中，使用〔加到主頁面〕
